# Portfólio — Laura Schiavon

Site pessoal de portfólio, construído com **Next.js (App Router)**, **TypeScript** e **Tailwind CSS**, com suporte a tema claro/escuro e tradução completa **Inglês/Português** (toggle na navegação).

## Funcionalidades

- Seções de Sobre, Skills técnicas, Direct Response & Growth Marketing, Projetos (com filtro por tecnologia) e Contato.
- Sistema de tradução EN/PT via Context API, com preferência salva no navegador.
- Animações com Framer Motion e componentes de UI baseados em shadcn/ui + Radix.

## Tecnologias

Next.js, React, TypeScript, Tailwind CSS, Framer Motion, next-themes, shadcn/ui.

## Rodando localmente

```bash
npm install
npm run dev
```
